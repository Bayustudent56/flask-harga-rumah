# Dashboard Analisis Harga Rumah D.I. Yogyakarta (Flask + Chart.js)

Kode studi kasus visualisasi data untuk mata kuliah Aplikasi Web.
Data di `data/rumah123_yogya_unfiltered.csv` berisi daftar properti rumah dijual di wilayah Daerah Istimewa Yogyakarta.

```bash
python -m venv venv
